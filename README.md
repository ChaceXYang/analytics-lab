# analytics-lab

Hands-on practice and portfolio projects on my path to becoming a data analyst.
Notes, plans and weekly reviews live in a private Obsidian vault (KnowledgeVault).

## Stack
Python · SQL · Tableau

## Structure
| Folder | Content |
|---|---|
| `py4da/` | Code-along notebooks for *Python for Data Analysis* (Wes McKinney, 3rd ed.), ch03–ch06 |
| `py4da/examples/` | Sample datasets used by the notebooks |
| `python/` | General Python practice: FreeCodeCamp course notebook, NumPy, pandas demo |
| `sql/leetcode/` | SQL practice solutions |
| `visualization/` | Matplotlib / Seaborn / Tableau exercises |
| `projects/` | End-to-end analysis projects (portfolio) |

## Progress
- [x] Python basics (FreeCodeCamp course)
- [x] NumPy fundamentals
- [x] pandas getting started (py4da ch05)
- [ ] Data loading, cleaning & wrangling (py4da ch06+)
- [ ] SQL intermediate (LeetCode database)
- [ ] First end-to-end portfolio project

## Conventions
- Notebooks are named by chapter, e.g. `Practicing_Ch3.ipynb`, `Pandas_Starter_Ch5.ipynb`
- Commit messages follow `chXX: topic`, so the history reads like a progress log
- Large/binary datasets are not committed; see `py4da/examples/README.md` for how to restore them
