# examples

Sample datasets for the *Python for Data Analysis* (3rd ed.) code-along notebooks.

Full official dataset: https://github.com/wesm/pydata-book

Small text files are committed here. The following large/binary files are **not** in git —
copy them from your local KnowledgeVault (`10-analytics/code/tmp/examples/`) or the official
repo into this folder after cloning:

- `ex1.csv` (book ch06 main dataset)
- `ex1.xlsx`
- `stinkbug.png`
- `yahoo_price.pkl` / `yahoo_volume.pkl`
- `fdic_failed_bank_list.html`
