# Freddie Mac 房贷 Vintage 违约分析与审批规则优化

> 🚧 进行中 · 2026 年 8 月 · SQL + Python（不使用任何机器学习模型）

基于 Freddie Mac 官方贷款级数据，用 SQL + Python 完成 Vintage 账龄分析与逾期转移矩阵（Roll Rate），产出可解释的贷前审批规则建议。

## 一、业务问题

**哪些年份、哪些特征组合的放款批次（vintage）违约率最高？如果用 FICO / DTI / LTV 规则收紧审批，能以牺牲多少通过率为代价，拦截多少违约？**

对应真实岗位场景：银行 / 消费金融机构风控分析师的两项日常工作——资产质量监控（vintage 报表）与审批政策评估（规则阈值测算）。

## 二、数据来源

- [Freddie Mac Single Family Loan-Level Dataset](https://www.freddiemac.com/research/datasets/sf-loanlevel-dataset)（官方发布，免费注册下载）
- 数据从 1999 年持续更新至近年 vintage，包含 2020 年后疫情期放款批次
- 结构：每个 vintage 由 **放款文件（origination）+ 月度还款表现文件（performance）** 两张表构成，天然适合多表关联与账龄分析
- 本项目使用官方年度抽样版（每年 50,000 笔），原始数据不提交本仓库，获取方式见 `data/README.md`

## 三、分析框架

| 步骤 | 内容 |
|---|---|
| 1. 明确分析目标 | 定位高违约 vintage 与高风险特征组合，评估审批规则的「拦截率-通过率」权衡 |
| 2. 数据清洗与探索 | 解析管道符分隔文本；识别 `999/9999` 编码缺失；放款表与表现表关联校验 |
| 3. 拆解问题维度 | 放款年份 / FICO 档 / DTI 档 / LTV 档 / 州 / 贷款用途 |
| 4. 归因与趋势 | vintage 累计违约率曲线、逾期状态转移矩阵、规则模拟测算 |
| 5. 结论与建议 | 输出审批规则建议（触发人工复审的特征组合 + 阈值），并说明局限 |

## 四、SQL 清单（规划中）

| # | 查询 | 技术点 |
|---|---|---|
| 1 | 放款表 × 表现表关联，算各 vintage 累计违约率 | 多表连接 + 子查询 |
| 2 | 各 vintage 违约率曲线与 3 期移动平均 | 窗口函数 `OVER(PARTITION BY ... ORDER BY ...)` |
| 3 | 逾期状态转移矩阵（相邻月 DPD 状态对比） | 自连接 + `LAG()` |
| 4 | FICO / DTI / LTV 分箱后的违约率 | `CASE WHEN` + `GROUP BY` |
| 5 | 各州 / 各贷款用途违约率 TopN | 窗口函数 `RANK()` |
| 6 | 规则模拟：不同阈值下的违约拦截率 vs 通过率损失 | 嵌套子查询 + 条件聚合 |

## 五、Python 清单（规划中）

- 管道符分隔原始文本解析，自定义 30+ 列名与数据类型
- **自定义函数处理 `999/9999` 缺失编码**（区分「真缺失」与「不适用」，面试重点讲解项）
- `np.select` 完成 DPD 分桶与 FICO 风险档划分
- `pivot_table` 输出转移矩阵与规则评分卡雏形
- Matplotlib 绘制 vintage 违约率曲线
